# Keyboard Landing Page

Overview

This is a fictional ecommerce landing page designed to showcase a product customers can purchase. This is done via persuasive design and calls to action.

Features

- Hero section
- Product highlights
- Customer reviews
- Multiple CTAs
- Responsive layout

TECHNOLOGIES USED

Given that this was just a landing page, I only relied on HTML and CSS. Leaning on Flexbox, I was able to make the page responsive for all devices. The content was all placed using HTML and CSS did the rest.

What I learned

- Building marketing focused layouts
- Responsive Flexbox layouts
- CTA placement

Future Improvements

- Shopping cart
- Product gallery
- Product variants
